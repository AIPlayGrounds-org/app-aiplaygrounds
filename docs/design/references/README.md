# Referencias visuales · AI PlayGrounds

## 1. Propósito del documento

Reunir la evidencia visual y las preferencias del responsable para orientar la próxima exploración artística del website institucional. La estructura de ocho páginas está aprobada; Inicio fue implementado en P05 y revisado en P05-R1 y P05-R2. El problema observado es una experiencia demasiado textual, con composiciones repetitivas y pocos recursos gráficos.

Este documento no aprueba una dirección artística ni A2, no modifica el contenido aprobado y no inicia el rediseño. Las capturas locales son la evidencia visual primaria; las webs enlazadas aportan contexto y pueden cambiar.

## 2. Estado de las decisiones

| Estado | Alcance |
| --- | --- |
| **Confirmado por el responsable** | Más protagonismo visual con sentido, variedad compositiva y personalidad; preferencia por un sitio predominantemente claro, acentos canónicos y trayectoria de jerarquía editorial como la presentación. |
| **Referencia visual** | Las capturas registran composiciones concretas, no decisiones para el website. Las externas no sustituyen la identidad propia ni autorizan copias. |
| **Candidato para exploración** | Pixel art elaborado, patrones modulares, transiciones ilustradas, cards expresivas, superposiciones e interactividad con propósito. Su forma y alcance no están decididos. |
| **Pendiente de aprobación** | Dirección artística, escenas, recursos originales, tratamiento de cada sección, comportamiento responsive y visual A2. Pixel art no es obligatorio en todas las páginas. |

## 5. Preferencias y restricciones de marca

1. **Identidad canónica:** el [manual de marca](https://github.com/edhutech/ppt-ai/blob/main/branding/branding-base.pdf) es la fuente primaria; la [especificación de apoyo](https://github.com/edhutech/ppt-ai/blob/main/branding/brand-spec.md) distingue reglas canónicas de derivaciones. Conservar Space Grotesk, Inter Tight y Geist Mono, los colores y el lenguaje de módulos, corchetes y órbitas. El símbolo se construye sobre una retícula 5 × 5, con núcleo y puertas; respetar sus reglas, sin deformarlo ni reconstruir un logotipo maestro no disponible.
2. **Extensión light del website:** conservar las superficies cálidas y tokens semánticos claros y oscuros existentes. Es una adaptación para el sitio, no una nueva regla canónica; la extensión light descrita en `brand-spec.md` es una propuesta para presentaciones, no una aprobación automática para web.
3. **Inspiración:** Cofounder, FIE Code Summit y Pattern Breaking orientan principios visuales, no reemplazan el branding ni autorizan copiar materiales. La presentación propia es referencia compositiva, no autorización editorial de sus cifras.
4. **Recursos nuevos:** explorar ilustraciones originales compatibles con AI PlayGrounds, incluyendo pixel art como candidato importante, sin decidir una escena ni extenderlo obligatoriamente a todo el sitio. Los cuatro conejos de las verticales ya forman parte de la identidad gráfica usada en el website: no sustituirlos por iconos genéricos.

Fuentes adicionales de la presentación: [narrativa](https://github.com/edhutech/ppt-ai/blob/main/deck/narrativa.html), [referencias del deck](https://github.com/edhutech/ppt-ai/tree/main/deck/reference/) y [deck generado](https://github.com/edhutech/ppt-ai/blob/main/output/deck.html). La jerarquía de marca prevalece sobre las referencias externas.

## 6. Dirección cromática

Guía orientativa para el website: **70 % superficies claras, 20 % oscuras y 10 % o menos de color intenso**. No es una cuota matemática: puede variar por página, contenido y composición. Es una preferencia para esta extensión web, no la proporción canónica del manual.

- **Claro:** predominio de superficies cálidas existentes.
- **Oscuro:** bloques estratégicos para contraste y ritmo.
- **Color intenso:** Halo `#8E8EFF`, Menta `#49FF9E` y Lima `#CEFF5F` en cards, gráficos, ilustraciones, destacados, fondos puntuales o interacción cuando corresponda. No modificar estos colores ni introducir una paleta nueva para el sitio; una ilustración puede emplear una gama más amplia si está justificada sin alterar la identidad.

Validar el contraste sobre el fondo efectivo y no depender solo del color para comunicar. El manual prohíbe texto blanco sobre Halo y acentos como texto sobre blanco; comprobar también los pares sobre superficies cálidas. No rellenar áreas para cumplir porcentajes.

## 8. Criterios para evaluar futuras propuestas

- **Identidad reconocible y coherencia de marca:** ¿se reconoce AI PlayGrounds sin confundir inspiración con identidad?
- **Calidad compositiva y jerarquía:** ¿escala, espacio y lectura dan relevancia a lo importante?
- **Valor de las ilustraciones:** ¿aportan significado y personalidad, con autoría original, en vez de llenar huecos?
- **Variedad sin saturación:** ¿hay ritmo y secciones memorables sin repetir cards, patrones o efectos por sistema?
- **Responsive:** ¿la composición y el contenido mantienen prioridad y legibilidad en móvil y escritorio?
- **Accesibilidad:** ¿contraste, texto alternativo cuando corresponda, teclado, foco y movimiento reducido están considerados? ¿La información se entiende sin depender del color o la animación?
- **Viabilidad técnica:** ¿los recursos son sostenibles en Astro, TypeScript, Tailwind CSS 4 y el sistema existente, considerando peso y rendimiento?
- **Contenido aprobado:** ¿se respetan arquitectura, mensajes, contexto, evidencia y destinos, sin omisiones silenciosas?
