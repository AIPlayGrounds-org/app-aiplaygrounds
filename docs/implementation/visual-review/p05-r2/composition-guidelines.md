# Criterios de composición · P05-R2

- **Hero:** un H1 de escala fluida y lectura completa, bajada que identifica la organización y acciones visibles. Un campo gráfico puede ocupar una columna si tiene relación explicable con la marca y no compite con el texto; en móvil pasa debajo sin recorte.
- **Editorial:** usar texto libre para ideas y relaciones, no una card por párrafo. Alinear título y cuerpo sin imponer simetría; el espacio negativo separa jerarquías, no rellena una altura fija. Enlaces descriptivos después del argumento.
- **Cards:** reservarlas para unidades comparables con contenido propio, como las cuatro verticales. No usarlas para encerrar toda la explicación de una sección. Preservar encabezados, lectura y foco naturales.
- **Evidencia:** cifras grandes siempre ligadas a periodo, unidad, actor y contexto; mantener atribuciones y fuentes junto a cada actividad. No presentar datos históricos como actuales. Una repetición gráfica debe ser redundante para tecnologías asistivas.
- **Marca:** Halo señala identidad y comunidad; no usarlo como texto pequeño sobre fondos claros. Geometría modular y espacios abiertos se inspiran en el manual, pero no son el logo. Las ilustraciones originales mantienen procedencia, proporción y colores; no reconstruir el wordmark ni crear favicon aproximado.
