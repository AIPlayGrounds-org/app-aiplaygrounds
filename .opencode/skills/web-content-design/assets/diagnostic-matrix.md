# Diagnóstico crítico y Matriz B0 / B1 / B2

La matriz es **la misma representación estratégica** en tres estados. No es cuestionario ni resumen progresivo: organiza, relaciona y cuestiona el brief, manteniendo procedencia, incertidumbre y consecuencias.

## Bloque por dimensión

Repite este bloque para cada una de las ocho dimensiones. Amplía en texto estructurado cuando una tabla resulte inmanejable.

```text
Dimensión:
- Información relevante del brief:
- Estado/procedencia (HECHO DOCUMENTADO / INFERENCIA / PROPUESTA / APROBADO / PENDIENTE; fuente, alcance y visibilidad):
- Relaciones con otras dimensiones:
- Contradicciones o tensiones:
- Vacíos relevantes y decisión que afectan:
- Implicaciones iniciales para la web:
- Puntos que podrían requerir research:
```

1. Organización, líneas de negocio y oferta.
2. Decisiones aprobadas, restricciones y fuera de alcance.
3. Resultados que la web debe ayudar a conseguir para la organización.
4. Público y sus problemas/necesidades.
5. Resultado que debe poder lograr el usuario dentro de la web.
6. Acciones/tareas reales y qué ocurre después de cada una.
7. Dudas, objeciones y criterios de decisión que la web debe resolver.
8. Evidencia, claims y diferenciación disponibles.

## Síntesis transversal

Relaciona explícitamente, cuando sea pertinente:

`organización/oferta → objetivo negocio → público → necesidad → resultado del usuario → dudas/objeciones → evidencia → acción real → restricciones`

Registra oportunidades, tensiones entre dimensiones, inferencias, decisiones que dependen de datos faltantes y preguntas que podrían cambiar materialmente la arquitectura, promesa, prioridad o research. No resumas la matriz eliminando detalles relevantes.

## Estados y gates

### B0 — provisional

Se crea inmediatamente tras el análisis crítico del brief. Muestra qué se entiende, qué está sustentado, contradicciones, vacíos, oportunidades, inferencias y cuestiones que podrían requerir aclaración o research. Se presenta al usuario y se detiene el avance: el usuario puede corregir/añadir información, confirmar/rechazar interpretaciones o pedir investigar un punto. Todo ello se registra como nueva información o decisión confirmada por el usuario; no se presupone quién originó el dato. Si el usuario pide explícitamente verificar una incógnita concreta, puede hacerse una verificación pública puntual desde B0: devuelve evidencia y propuesta/inferencia para que decida el usuario. No es research SEO formal, no crea B1 ni aprobación y no inicia clustering/Keyword Map por defecto. Después se espera decisión humana antes de B1.

### B1 — validada

Solo existe después de resolver el Gate A con confirmación humana inequívoca. Incorpora correcciones, adiciones y confirmaciones, conserva desacuerdos/pendientes y registra qué cambió. **Es la única base del research estratégico/SEO formal**; este research no se inicia desde B0, incluso después de una verificación puntual.

### B2 — consolidada

Después del research, presenta evidencia, hallazgos y propuestas de conclusión para revisión humana. Research no aprueba ni cambia la matriz automáticamente. Tras aceptación/corrección/rechazo explícitos del usuario, incorpora únicamente lo aceptado; lo demás permanece como evidencia, hipótesis o pendiente. Registra estado y procedencia de cada cambio. B2 es la base de O/C, estrategia y arquitectura.

## Síntesis obligatoria de clusters aprobados en B2

`cluster | nivel | necesidad | intención | keywords representativas | señal/evidencia | prioridad | página responsable propuesta | cluster padre/hijos | riesgo de solapamiento | implicación estratégica | estado`

Si el research formal produjo clusters y el usuario los aceptó en Gate B, B2 debe registrar explícitamente los elementos aprobados que condicionarán las etapas siguientes. Cuando existan, incluye cluster, nivel, necesidad, intención, keywords representativas, señal/evidencia relevante, prioridad, página responsable propuesta, relación padre/hijos si existe, riesgo de solapamiento cuando aplique, implicación estratégica aprobada y estado. No copies el Keyword Map completo: este conserva el detalle integral del research y B2 su síntesis aprobada para O/C, estrategia y arquitectura. Si el research no justificó clusters, no los inventes.
